## 🌟 프로젝트 소개
- HTML, CSS, JS 기반 반응형 포트폴리오 사이트
- 섹션별 스무스 스크롤과 인터랙티브 UI 제공
- 프로젝트 카드 클릭 시 모달로 상세 정보 확인 가능

---

## 🆕 이번 업데이트 주요 기능
### 1. 프로젝트 필터링
- 카테고리별 프로젝트 표시/숨기기
- 그리드 순서대로 스르륵 올라오는 애니메이션 적용

### 2. 스크롤 인터랙션
- 섹션 진입 시 페이드 인 / 슬라이드 인 애니메이션
- 현재 보고 있는 섹션 메뉴 자동 하이라이트
- TOP 버튼(arrow-up) 클릭 시 부드럽게 최상단으로 이동

### 3. 다크 모드 / 라이트 모드 전환
- 버튼 클릭으로 다크 모드와 라이트 모드 전환 가능
- 상태에 따라 버튼 아이콘 변경

### 4. 시간대별 인삿말
- 페이지 접속 시간에 따라 아침/오후/저녁 인사 메시지 표시

### 5. 프로젝트 모달
- 프로젝트 카드 클릭 시 모달 오픈
- 모달 닫기 버튼과 외부 클릭 시 모달 닫기 가능
